# Place content in the visual canvas

Open a page's visual canvas. Select a section, open **Links and body blocks**,
choose the content and add it. In **Layout settings**, use **Move block to
section**, **First column** and **Column span** to place the selected block.
**Duplicate selection**, **Delete selection**, **Undo** and **Redo** apply to
these blocks. Saving changes prepares a draft; publication remains separate.

Text accepts headings, paragraph styles, inline emphasis, one nested list level
and paragraph alignment. Paste supported Word or Google Docs content to keep
semantic headings, lists, emphasis and safe links. Scripts, remote images and
unsupported markup are removed.

Buttons have primary, secondary and tertiary appearances. Choose a saved page
or anchor reference to keep a destination attached when its URL changes.

Use **Audio** to upload an MP3 or M4A, choose it from **Library audio**, and set
a title and the download choice. Files are limited to 512 KiB each within the
existing file-library budget. Only approved audio referenced by a public page
is delivered. Alternatively, provide a SoundCloud track widget or Spotify
embed URL. Video, map and social embeds use the same external-content consent
controls, including immediate withdrawal and privacy opt-outs.

Create a reusable form in **Form settings**, select it in the page's **Form
placement**, then add a **Page form** block to position it in a section.
Duplicated form placements keep separate field identities. **Page HTML embed**
places the owner's existing page code; code remains isolated and requires the
existing publication and visitor consent steps.

For **Summary** or **Collection list**, select a collection, list or grid
layout, item limit, sort field and optional exact-value filter. The published
block reads the approved collection, so unpublished item changes stay private.
Relative date filters and visitor-controlled filters remain separate work.

**Booking and checkout** adds a booking handoff, product card or buy button.
Choose the provider, its public HTTPS link and a clear handoff label. Products
also have a description and USD price. The visitor completes the booking or
payment with the provider; these blocks do not collect card information or
claim that a click completed a booking or purchase.

**Collection calendar** reads start and end date fields from an approved
collection. Choose its first month and list or month view. Visitors switch
views by keyboard; multi-day items occupy every included day and open the
native collection item page. These are all-day dates. Timed and recurring
events, request-time upcoming and past groups and calendar exports remain
CMS-009 work.

Open **Settings** in the page editor to choose heading and body fonts,
colors, button shape and page spacing. Built-in and uploaded fonts use the
existing owner-controlled styles. Changes stay private until publication;
earlier revisions retain their styles for preview and rollback. Sections
inherit the site background unless a local background is set. **Reset layout**
restores the section defaults. Adobe Fonts remain STYLE-002 work.

Newsletter collection remains unavailable until LINK-003 has an authorized
Mango or Mailchimp audience. The provider must receive explicit signup and
consent, return its actual outcome and honor suppression (ct RL-102).
