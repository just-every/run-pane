# Photographic upload fixture

`apollo17.jpg` is a 1200-pixel JPEG derivative of NASA's public-domain Apollo 17 photograph of Earth (AS17-148-22727), photographed by the Apollo 17 crew in 1972. Source: <https://upload.wikimedia.org/wikipedia/commons/9/97/The_Earth_seen_from_Apollo_17.jpg>. The responsive-image journey creates a 6000-pixel local upload from this fixture through the browser canvas, then uses the ordinary image picker and publication flow. This is a product test fixture, with no production or visitor data.
