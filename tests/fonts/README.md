# Font format fixtures

These three small fonts are ASCII subsets of the existing Figtree face, renamed Synthetic Pane Test. WOFF and TTF use its static regular outlines; OTF carries the same outlines converted to cubic CFF curves. They exercise real browser font decoding, with no network font provider. The original face and its [SIL Open Font License](../../public/fonts/figtree/OFL.txt) remain in the repository.
